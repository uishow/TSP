3. 数据链路

浏览器 /custom/new-watchlist
  ├─ GET  /api/watchlist/enriched          → 全部自选行指标（现价/涨跌幅/换手/RSI/动量/信号/加入以来）
  ├─ GET  /api/watchlist + /groups         → 分组过滤
  ├─ POST /api/kline/daily-batch {symbols,days:60}  → 日K迷你蜡烛
  ├─ POST /api/kline/minute-batch {symbols,date}    → 当日分时迷你线
  └─ GET  127.0.0.1:3021/bigorder/snapshot?symbols=... → 主力净额 → 占流通市值%

三项增强数据一次性批量拉取，避免逐股 99 次请求；15 秒刷新一次，图表与资金流不阻塞主表先渲染。
