0. 总览与端口一览

一句话：整个系统 6 个常驻服务、约 220 条 HTTP 接口 + 1 个 socket 服务；行情实时腿在 eltdx / 东财 / 同花顺，历史腿全部走本地 parquet（回测不联网）。

端口服务运行方式数据源实时性
3018主应用 TSP（docker tsp-local）docker compose本地 parquet + 桥接7818本地为主
7818行情桥接 bridge宿主 python（uvicorn）eltdx + 7899 + TDX .day实时腿
3021大单监控 bigorder_adapter宿主 uvicorn东财 push2 + 同花顺 + eltdx实时
3022异动信号工作台 anomaly_signal宿主 uvicorn本地 TDX 数据 + 3021本地+实时
3023涨跌停时间轴 limit_timeline宿主 uvicorn东财 push2ex 直连实时
7899free-stockdb stockdb-server独立二进制本地 stockdb 数据库本地
主应用 3018 是唯一对浏览器直接服务的入口（SPA + 扩展页进程内路由）；3021/3022/3023 是旁路数据服务，只对页面 JS 开放（CORS 允许 3018 域）；7818/7899 只被后端调用，不对浏览器开放。全部服务都绑 127.0.0.1，不出内网。

1. 数据流架构图

【实时腿（盘中）】 eltdx 3.3.5 (TDX主站 TCP)──┐ 东财 push2/push2ex (HTTP) ──┤ 同花顺 d.10jqka (HTTP) ──┤ ├→ 3021 大单监控（东财+同花顺+eltdx五档） ├→ 3023 时间轴（东财三池） └→ 7818 桥接（eltdx实时/五档/财务）→ 容器3018 实时worker 【历史腿（本地，回测专用）】 TDX .day 文件 ──┐ free-stockdb 7899 ──┤→ 7818 桥接 LocalStore → 容器3018 │ 落盘 kline_daily → enriched → 回测只读 parquet fuyao 离线包 ──────┘（财务/分类旁路） 【盘后腿】 15:35 管道 → regime + 主线（日更）→ /api/regime/* 15:02 depth5 定版 → data/depth5/date=xxx/part.parquet 【页面消费】 浏览器 → 3018（主页面+扩展页） ├→ /api/overview/market（KPI六宫格） ├→ /api/watchlist/enriched（新自选） └→ 旁路直连 3021/3022/3023（页面 JS fetch）
11-19 盘中实测结论：「看板延迟感」来自三条腿节奏差——东财腿（时间轴）秒级实时；KPI 腿 = 本地日线分钟级滚动 + depth_service 五档修正约 10~120 秒轮询（TickFlow 套餐限速）；regime 腿 = 盘后日更。三块数字不同拍是口径差异，不是故障。

3. 桥接 7818 接口（行情统一入口）

方法路径认证说明
GET/health无健康检查
GET/status需桥接各数据源状态
POST/query需统一行情查询：daily / minute / realtime / depth5 / financial / instruments。容器 3018 的实时 worker 与历史补数都从这里走
数据源优先级（live_sources.py）：实时/五档/财务/当日分钟走 eltdx（TSP_LIVE_BACKEND 可切 axdata）；日线/分钟历史走 free-stockdb 7899 + TDX .day；回测只读本地 parquet 不过桥。fail-closed：本地判需刷新而实时源返回空时直接报错，不伪造（bridge/router.py:308）。

6. 涨跌停时间轴 3023 接口

方法路径说明
GET/health、/健康 / 页面
GET/api/limit-pool/timeline?date=YYYY-MM-DD&refresh=0|1东财 push2ex 直连实时：涨停/炸板/跌停时间轴 + 梯队 + 涨停原因。refresh=1 跳过服务端短缓存强制回源（前端「重载」按钮用）。返回含 server_time / in_session / stale / counts{zt,zb,dt}
11-19 11:0x 实测：server_time 与墙钟一致（秒级实时）、stale=false。这是全系统实时性最高的一条腿。

7. free-stockdb 7899（socket 服务，不对浏览器开放）

独立二进制 stockdb-server（数据目录 ~/private/stock/数据汇总/本地量化数据/），socket 协议。由 bridge/local_store.py 通过 stock_sdk.init(host='127.0.0.1', port=7899) 接入。

能力消费方说明
日线 bar（source=free_stockdb）7818 LocalStore.daily() → 容器落盘 kline_daily历史回填主源之一
分钟 bar7818 LocalStore 分钟路径本地分钟线
bar 不带 name 字段 → instruments 名称靠 eltdx 代码表按日缓存补齐。回测不直连 7899（保 sha256 可复现），只读已落盘 parquet。
