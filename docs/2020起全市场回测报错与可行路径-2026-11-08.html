四、页面怎么点（限池路径）

① 在回测页限定股票池
点哪里：回测页左侧「策略设置」卡片 → 找到「股票池 全市场」那一行 → 点右侧「编辑」
会发生什么：展开一个输入框，占位文案是「搜索股票名称/代码添加股票池」，可输入代码、支持逗号分隔多个
结果在哪看：卡片文案从「股票池 全市场」变成「股票池 已限定 N 只」；前端据此在请求里带上 symbols
出错怎么查：如果仍是「全市场」，说明没保存成功，重新点编辑添加；页面说明文案是「需要单票调试或自选池回测时再限定股票池；默认由基础过滤、策略条件与买卖触发器在全市场筛选」

结果在哪看：约 20~60 秒出净值曲线与交易列表，底部显示「2020-01-01 ~ 2026-11-07 · 1658 天」，不再出现 -9。若不限定池子（方案 C 全市场），则约 80~90 秒
出错怎么查：若报「内存超过上限 36GiB」→ 软限触发，缩小池子或分段；若仍报 -9 → 检查 docker info --format '{{.MemTotal}}' 是否仍是 39.10 GiB（GUI 调整过会回落）
③ 现有自选股可直接用
服务端 /api/watchlist 当前有 2 只自选（002058.SZ 紫竹高科、002474.SZ 榕基软件）。若想用自选池，可在股票池里添加这些代码；只有 2 只时策略可能「未产生买入信号」，建议配合更多标的
