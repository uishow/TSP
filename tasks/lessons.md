# Lessons

- 数据源范围被进一步明确时，立即终止不符合新口径的自动拉数；保留已有数据及日志并隔离来源。接入验收同时覆盖启动、定时器、指数/ETF、日历与失败回退路径，不能只更改设置页主路由。
- 本地统一读取指南需要与实际实现核对：跨历史与近端的复权参数传递、8位日期结束边界、成交量单位必须用独立样本验证，不能只依赖接口名称。

- 每个数据集必须能作为服务重启后的首个请求独立工作；板块依赖的SDK搜索路径应由本数据集显式初始化，不能依赖此前已有日K请求。
- 同一资产类型的本地成交量编码也可能不同。价格/量额必须按真实样本与金额-均价约束验证，不能将一个ETF样本的单位推广到全体；未证明的量保持null。
- 确认下游是否保留质量标记。仅在桥接返回stale不足以阻止原生流程把null时间快照落为当日行情，未验证的时钟能力应停留在观察入口。
- 日期字符串与datetime字符串不得直接混用比较边界；按数据粒度规范化后做闭区间比较，并验收导入窗口第一天。

- 用户提到“8/28”等含糊编号时，先确认是日期、买点编号还是界面计数，再定位；本次用户明确指“8买点、28买点”，不能用预警日期保留策略解释。
