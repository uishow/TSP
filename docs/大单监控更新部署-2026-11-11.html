3. 怎么用（点哪里 → 发生什么）

入口TSP 左侧栏「大单监控」（按 F5 刷新后出现 / 更新） 切票页面输入框打代码（如 002639 或 002639.SZ）回车 档位选「500万」等阈值 → 气泡与逐笔表同步过滤（严格 amt >= th，非 th/2） 剔除勾「剔创业板 / 剔科创板」→ 300/301/688 开头消失 在线状态右上角「ELTDX 在线」= 3021 通；「离线」= 3021 没起或端口错 结果在哪看分时图 + 大单气泡（买红卖绿）+ 四档净额 + 量化分析卡 + 全市场主力净额榜
出错怎么查
  • 白屏：F12 看 console；多半 page.json 的 sha256 与 bundle 不符（本次已校验一致）
  • 四档全 0：上游（东财/同花顺）限流，等几秒刷新；或看 /bigorder/flow 报错
  • 买卖全反：有人把逐笔 1=卖 2=买 改回「1=买」（铁律 5.1，勿改）
  • 封单「未采样」/ 竞价「未采集」：未装采样器/巡检器，属正常

4. 启停策略（条件启停 · 用户第 6 项指令）

大单监控适配器遵循「盘中启用、盘后关闭」策略，不做常驻 launchd 自启（与策略冲突；收盘后 3021 关闭是正确行为）。

场景操作
交易时段要用执行第 2.4 节的启动命令（后台常驻），页面右上变「ELTDX 在线」
收盘后停掉 3021 进程即可（页面显示「离线」，不影响 TSP 其他功能）
重启 Mac 后需手动再起一次（无 launchd）；如需常驻可后续单独评估

本次为验证部署已手动启动 3021；若要停，结束该后台进程即可。

5. 未做部分（明确告知）

按用户此前「封单采样器 / QQ 提醒 / 竞价强度采集 —— 先不做」的决策，本次未部署：

  • watcher/ 巡检器（连续大单 / 封单骤降 → QQ 推送）—— 不装，页面横幅提醒仍可用
  • sampler/ 封单采样器（每 10s 拍五档落 ndjson）—— 不装，/bigorder/seal、/bigorder/auction 显示「未采样 / 未采集」

adapter 代码已含这些接口，未来要启用只需补装 sampler/watcher 并把数据写进 services/bigorder_adapter/data/，无需改页面或适配器主逻辑。

6. 升级兼容性（二开铁律）

  • 扩展页在 data-local/ext_pages/（挂载卷，非容器内 /app/app），适配器在 services/（宿主进程）。两者都不触碰镜像、compose.yaml、upstream/。
  • 升级 TSP 镜像后：扩展页与适配器照常挂载/运行，不会阻断启动；按 §8 重跑验证即可。
  • 若上游原生大单功能改变，仅需重新核对 page.json 契约与 3021 路由，无耦合风险。
