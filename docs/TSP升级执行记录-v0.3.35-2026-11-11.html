5. 唯一失效项与修法（技术细节，可跳过）

为什么只有它会失效？

这个补丁的机制是：用正则认出前端那个回测分块文件（不写死带哈希的文件名，所以升级不会因为文件名变了而失配）， 然后对里面压缩后的代码做精确文本替换。v0.3.35 重新压缩了一遍，变量名几乎全换了，所以旧的替换文本找不到原句，整份自动退回原版。

v0.3.34 叫什么v0.3.35 改成了
状态 setter R / Lg
策略列表查询 Uele(...) 包装
预设列表 Leke
就绪判断 xt / _s_s（仍同名，位置变）
标签 GrYr
自选池 EoXo
运行处理 Zixl
守卫 fsvs

怎么修的

在 overrides/multi_asset_patch.py 里新增了第三套锚点 _REPLACEMENTS_V035（10 条，语义与旧版 11 条完全一致—— 其中「有效资产类型」和「增强数据就绪探测」两条在新版里合并成了一条，因为新版把有效资产声明在同一个 const 声明列表里、紧挨着 _s 之前）。

_PROFILES = (
    ("v0.3.35+", _REPLACEMENTS_V035),   # 新版：10 条
    ("v0.3.34+", _REPLACEMENTS_V034),   # 旧版：11 条
    ("v0.3.31",  _REPLACEMENTS_V031),   # 更旧：11 条
)

三套并存的意义：以后无论回滚到旧版、还是再升到更新的版本（只要压缩后的变量名不变），都有一套能命中； 全都命中不上就安全退回原版、只打一条 SKIPPED，页面永远不会白屏。
