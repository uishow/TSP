1. 平台能做什么（先知道手里有什么工具）

官方因子平台不是「点一下自动印钱」，而是一套从想法→检验→策略→回测→模拟盘的研究管线。三个工作台：

工作台干什么关键能力
发现批量筛选 / 挖掘工作台嵌套样本外：训练区间重估方向→相关性去重→多因子排名组合搜索；自有策略作对照轨
创建公式编辑器 / 因子组合DSL 写公式（如 rank(-ts_sum(change_pct,5))）；25 个算子按时序/截面/工具分组；语法校验(错误定位到字符)；试算 40 日 IC；存草稿
因子库95 个注册因子管理状态机 草稿→(检验通过)→激活→观察/退役；公式改了存新版本回草稿；「检验此因子」「生成策略」一键联动
服务端检验口径（不用自己算）： IC / IC 胜率 / Newey-West 稳健 t 值 / BH-FDR 多重校正 q 值 / 分层收益 / 多空对比；支持批量检验一次评估多个因子。
一条龙联动（这是平台的真正价值）：
  • 因子库「生成策略」→ 一键生成单因子排名策略（entry/exit 评分阈值 + top_rank），保存即可回测
  • 策略触发器 Zap 按钮 → 从因子快速建条件信号（阈值给建议值），自动挂接到入场/卖出触发器
  • 自定义信号 AI 生成提示词 → 含全部因子分组与 id，可直接写「因子·动量: momentum_20d > 0.8」类条件
  • 策略回测「因子归因」tab → 对比盈利单 vs 亏损单在入场信号日的因子均值（胜单均值明显高=该因子有正筛选力）

2. 检验指标含义（怎么判断一个因子"有用"）

指标它告诉你什么及格线（经验）
IC（信息系数）因子值与未来收益的秩相关；绝对值越大，预测力越强|IC| 越高越好，>0.03 算有信号
IC 胜率分周期里 IC 为正的比例；看稳定性，不是偶尔灵≥60% 较稳
Newey-West 稳健 t 值考虑自相关/异方差后的显著性；防"看起来显著其实噪声"|t| > 2（约 95% 置信）
BH-FDR q 值你筛了成百上千个因子，多重检验校正后还显著吗q < 0.05 才算真显著
分层收益按因子值分 5 组，第5组(高)收益是否单调优于第1组(低)单调、且头尾差明显
多空对比做多第5组+做空第1组的净值是否稳定向上回撤可控、长期为正

一句话：IC>0 且 IC 胜率高 + Newey-West |t|>2 + BH-FDR q<0.05 + 分层单调 + 多空稳定，五个条件同时过，才算"有用"的候选因子。

3. 挖因子 5 步法（映射到平台按钮）

1写候选因子（创建 → 公式编辑器）
从动量/波动率/量价/收益形态四大类入手，用 DSL 表达想法。例：rank(-ts_sum(change_pct,5))（近5日跌幅越大越靠前=反转思路）。先点试算 40 日 IC，把 |IC| 接近 0 的当场丢掉，省时间。

2完整检验（因子库 → 检验此因子 / 批量检验）
跑上面 §2 的全部指标。只留同时通过五项门槛的；批量检验一次评估一组候选，效率高。

3防过拟合（发现 → 挖掘工作台）
用嵌套样本外：训练区间重估因子方向、相关性去重（去掉高度雷同的冗余因子）、多因子排名组合搜索，并以自有策略作对照轨。候选入库须显式确认才发布、永不自动上线。

4确认方向 + 生成策略（因子库 → 生成策略）
回测前必须确认因子方向（值越大越好 or 越小越好，平台会提示）。一键生成单因子排名策略（评分阈值 + top_rank），保存进策略库。

5回测 → 模拟盘（策略页 → 回测 → 模拟盘）
回测叠加真实约束（T+1 / 佣金 / 印花税 / 滑点 / 最大持仓 / 止损）；用步进优化(Walk-Forward)看样本外是否退化；最后进模拟盘虚拟资金向前跟踪，确认"现在敢不敢跟"。

4. 落到 TSP 的具体点法

打开平台左侧栏「因子」→ 进入 /factors 一级页 写公式「创建」→ 公式编辑器 → 输入 DSL → 右侧 25 算子可点击插入、悬停看签名 试算编辑器内「试算 40 日 IC」→ 看初筛结果 正式检验「因子库」→ 选因子 → 「检验此因子」（或「批量检验」） 变策略因子详情 → 「生成策略」→ 填 entry/exit 阈值与 top_rank → 保存 看归因策略回测结果 → 「因子归因」tab（胜/败单因子均值对比）

平台内置"从模板开始"下拉（经典模板 + 我的因子），不会写 DSL 也能从模板改起。

5. 避坑清单（为什么很多因子"看起来能盈利其实不能"）

  • 过拟合：在一个历史区间里反复调参数，IC 很好但样本外崩。→ 必须用挖掘工作台的嵌套样本外 + 步进优化验证 OOS。
  • 方向搞反：回测前没确认因子方向（越大越好/越小越好），信号全反。→ 平台会提示，务必确认。
  • 未来函数：因子用到"当时看不到"的数据。→ TSP 回测两阶段隔离、分钟成交用下一根 K 开盘价，严禁未来数据；自定义因子也要自查。
  • 多重检验作弊：筛了 1000 个因子挑最好的，其实只是运气。→ 看 BH-FDR q 值，q<0.05 才算真显著。
  • 单因子 ≠ 业绩：因子只证明"有筛选力"，叠加 T+1/费用/止损/仓位后才是可交易结果；历史最优参数≠未来最优。
  • 分层不单调：第5组收益不比第1组好，说明因子区分度差，别硬上。
铁律：候选入库永不自动上线，必须显式确认才发布；回测过关后去模拟盘用虚拟资金向前跟踪，再决定是否真跟。
