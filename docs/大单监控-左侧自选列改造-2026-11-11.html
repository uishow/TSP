1. 这次改了什么（大白话）

用户原话：「改造『大单监控』，在页面左边新增一列，拉取并显示 TSP 中的『自选』股票，然后把大单监控的股票入口变成页面上的股票点击选择。」

项目改之前（v3）改之后（v4）
选股票顶部有个输入框，得打字输代码/名称，再按回车或点下拉建议页面左边多一列「自选」，点一下股票就切换；顶部只显示「当前：名称 代码」，不用打字
看自选看不到，得切到 TSP 自选页左列直接列出 TSP 自选全部股票，带现价、涨跌幅、分组；可分组筛选、可搜名称/代码

右栏榜单点榜单行也能切票保留不变，是第二个点击选股入口
原有功能分时图 / 大单气泡 / 四档净额 / 量化分析 / 封单质量 / 竞价强度 / 全市场榜 —— 一行未删，只是整体挪进右侧主区
一句话：以前「打字找股票」，现在「左边列表点股票」。第一次打开会自动选中自选第一只；之后你点哪只就记住哪只，下次进来还是那只。

6. 出错怎么查

  • 左列空白 / 显示「读取失败」：先看 TSP 在不在（/health）；再点左列「刷新」。TSP 里还没加自选时会提示「请先到自选页添加」。右侧大单监控不受影响。
  • 左列有名字但没有价格/涨幅：:3021 适配器没起（收盘后按策略会关），属正常降级；盘中要用就按 docs/大单监控更新部署-2026-11-11.html §4 起三服务。
  • 页面白屏：多半 page.json 的 size/sha256 与 bundle.js 不一致。查 GET /api/ext-pages 的 error 字段，并复核 shasum -a 256 bundle.js。
  • 点了股票右侧没变：看右上角「ELTDX 在线 / 离线」；离线=3021 没起。左列高亮和顶部标签仍会变（这部分不依赖 3021）。
  • 改了代码没生效：TSP 扩展页会缓存，Cmd/Ctrl+R 强刷一次；再不行看 /api/ext-pages/big_order/bundle.js 返回里有没有 bo-layout。

7. 升级兼容性（二开铁律）与回滚

  • 只动了 data-local/ext_pages/big_order/ 下的 bundle.js + page.json —— 这是 TSP 原生扩展页机制的挂载卷，不是容器里随镜像分发的 /app/app / /app/static。未碰镜像 / tag / digest / compose.yaml / upstream/ / 3021 适配器代码 / 任何数据口径。
