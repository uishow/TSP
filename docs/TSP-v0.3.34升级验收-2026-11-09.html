def patch_source(source):
    for profile, replacements in _PROFILES:
        out = source
        for old, new, label in replacements:

            out = out.replace(old, new, 1)
        else:
            return out, applied, profile

11.4 出问题怎么查

  1. 页面打不开：docker ps 看 healthy；docker logs tsp-local 2>&1 | tail -60。所有二开都是「装载日志 + 安全降级」，不会白屏。

  4. 数据看起来少了：一律用 DuckDB 直查分区，不要看 /api/data/status 的 rows:0（那是恒定设计）。
