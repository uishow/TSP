剩余 11 个 DS 策略调参验收

承接前两只策略（W 底 / 强势洗盘）的同一套方法，把剩余 11 个 DS 策略也做了「防追高过滤 + 风控网格 + 默认写回 + 样本外验证」。全部改动都在挂载卷 data-local/strategies/custom/，策略页直接点运行就是终版参数，无需手填覆盖值。不动镜像 / digest / compose / upstream / 回测口径 / 行情数据。诚实结论：11 个里 4 个做到历史与样本外双正、2 个历史微利但样本外转负、4 个调参后仍负收益、1 个始终无信号——后 5 个不建议实盘，已在策略页如实标注。

2. 改了什么

每个策略文件改两类内容，均为挂载卷内的自定义策略文件：

2.1 风控默认值（写回模块常量）

STOP_LOSS     = -0.20      # 各策略按网格最优写回，不再靠手填 overrides
TAKE_PROFIT   = 0.04
MAX_HOLD_DAYS = 10

引擎在加载策略时读取这三个模块常量作为默认值（已在容器内实测：详情接口返回 stop_loss=-0.2 / take_profit=0.04 / max_hold_days=10），所以策略页默认运行即用终版参数。

2.2 防追高过滤（guard 包装器）

新增共用文件 data-local/strategies/custom/_ds_common_filter.py，以 _ 开头不会被策略发现器注册成独立策略。GuardedMatrixStrategy 只过滤 entry，出场 / 评分 / 信号码完全沿用原策略；所有条件只用截至信号日 t 的 trailing 数据，前 5 根显式置 NaN、无 bfill、无居中窗口，无未来函数。

quality = (close/MA20-1 <= max_extension) & (close/prev_close-1 <= max_change)
        & (MA20/MA20[t-5]-1 >= min_slope) & (close/close[t-5]-1 <= max_recent_gain)
entry = 原 entry & quality     # 只砍买入，不动卖出/评分

三种 guard 强度按各策略最优结果所属轮次恢复：宽阈值（default，0.12/0.08/−0.005/0.35）用于 2560、不朽指引、早晨之星、主升低吸；紧阈值（tight，0.05/0.04/0.002/0.15）用于多重金叉、多方炮、底部拐点、涨停回马枪、涨停横盘、趋势加速；阻力位突破不包 guard。

3. 怎么比出来的

3.1 三轮网格分工

轮次文件状态风控组合（5 组）作用
risk原始信号，无 guardbase / TP3%-SL15%-8日 / TP2.5%-SL20%-10日 / TP4%-SL20%-10日 / TP2.5%-SL12%-6日看原策略在合理风控下的底色
guard宽阈值 guard温和防追高

共 11 策略 × 3 轮 × 5 组 = 165 个组合（实际因无信号略少）。统一撮合口径：open_t+1 次日开盘成交、10 仓等权、费 0.02%、滑点 5bp、2023-01-03~2026-11-17。每个组合都跑未来函数检查，全部 passed。

3.2 guard 为什么有效

前面的根因诊断已确认：原策略在信号日大涨后，次日 open_t+1 高开追入，频繁触发止损导致巨亏。guard 过滤掉「信号日涨幅过大 / 离 MA20 过远 / 近 5 日涨太多」的 entry，从源头避开追高。例如多重金叉 raw 版 TP4%/SL20% 是 −12.64%，加 tight guard 后同风控变 +31.59%。

7. 回滚与升级兼容

回滚：用 data-local/strategies/custom/*.py.bak_20261118_2145（原始未调参版）覆盖同名 .py，再 POST /api/strategies/reload 即恢复。共用过滤文件 _ds_common_filter.py 可保留（无人引用时无害）或一并删除。
升级兼容：全部在挂载卷自定义策略目录，TSP 升级不覆盖 data-local/；升级后若策略加载失败，查看日志里的策略加载错误——极端情况下 guard 依赖的 make_signal_matrix 接口若上游变动，策略会加载失败而非白屏，按备份回滚即可。不动镜像 / digest / upstream。
边界：历史统计不等于未来收益，本文档不给任何买卖建议；小止盈+宽止损仍保留单笔大亏可能；回撤 −36% 的多重金叉虽样本外为正，实盘需自行控制仓位。
