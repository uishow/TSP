一、现象（用户报告）

用户在回测页 /backtest?tab=strategy（浏览器经 127.0.0.1:3081 访问）发现：

  1. 策略无法选择：「选择策略」面板显示 当前分组暂无策略，四个分组标签为 全部 / 自定义 / AI / 叠加，下方为空。
  2. 参数也消失了：因未选中任何策略，「策略设置」区域显示 未选择策略，原本可调的参数（动量回看天数、R² 下限等）不再出现。

截图文字与容器内当前前端包 Backtest-BghTRouv.js 的空态字符串 完全一致（均为「当前分组暂无策略」），说明用户浏览器运行的就是当前版本前端，不存在前端版本错位。

二、数据流链路

前端 Backtest 包→ Q.strategyList()→ GET /api/strategies?timeframe=1d→ 引擎 list_strategies()

关键代码事实（静态核查）

  • 前端 API 客户端：strategyList(e, t="1d", n=false) 拼装为 /api/strategies?asset_type=<e>&timeframe=<t>。空 e 不传 asset_type。
  • 回测页调用点 全部为无参 Q.strategyList() → 真实请求 = /api/strategies?timeframe=1d。
  • 默认分组标签 useState("all")，过滤逻辑 p==="all" ? Le : Le.filter(s=>s.source===p)；全部标签下显示所有策略。
  • 空态仅当 !loading && bn.length===0 触发，即「接口返回了 0 条」才会显示。

结论：只要接口返回 ≥1 条，前端就会渲染。空面板 = 浏览器这次拿到的策略列表是 0 条。

四、根因分析

前端代码与后端引擎当前均正确：3018 实时返回 2 条 ETF 策略，前端逻辑会在拿到 ≥1 条时渲染卡片。空面板只能解释为浏览器这次请求拿到了 0 条。两者结果不一致，差异只发生在「浏览器 → 3081 转发 → 容器」这一段。

最可能的两类原因：

  1. 浏览器侧 stale 缓存（最可能）：页面在策略尚未注册进运行容器时加载，React Query 把「空结果」缓存住；之后虽有 reload，但页面未刷新仍显示旧空值。已实测 我已触发 /api/strategies/reload，3018 现返回 2 条 —— 硬刷新即可恢复。
  2. 3081 转发 / 浏览器代理问题（次可能，我侧未验证）：若浏览器把 127.0.0.1:3081 的 /api/* 请求经系统 HTTP 代理转发，而该代理无法回环到本地转发，会返回 502/非 JSON，前端解析失败 → strategies 为 undefined → 视为 0 条 → 空面板。本机曾有「代理导致 localhost 取数 502」的先例（见环境踩坑）。
注意：即使面板恢复，本版本只有 2 只 ETF 策略，没有任何股票策略。若您记忆中「以前可选的参数」是股票策略的参数，它们属于更早版本，已在 v0.3.31 被移除（内置策略目录仅剩 __init__.py 与一个 research 草稿）。这不是 bug，是策略库现状。

六、修复与结论

  1. 已做：在 3018 触发 POST /api/strategies/reload，确认后端返回 2 条、无加载错误。已端到端实测
  2. 请您做：对 3081 页面执行硬刷新；若仍空，按第五节看 Network 响应定位是「缓存」「错实例」还是「代理/转发」。
  3. 结论：这不是前端选择器代码缺陷，也不是后端取数缺陷（3018 实测正常）。空面板 = 浏览器经 3081 拿到的策略列表为空，根因落在「浏览器缓存」或「3081 转发/代理」两处之一，可由上面的 Network 自检验证。

七、重要提醒

  • 本版本策略库仅含 2 只 ETF 策略（custom_qx175_etf_rotation、custom_simple_ma_cross），asset_types=["etf"]、timeframes=["1d"]。
  • 若您需要股票回测，当前没有任何股票策略可选 —— 需新增一只股票策略（写 data-local/strategies/custom/*.py 并 reload）。否则回测页股票维度永远为空，这与「以前可选」的观感差异属同一来源。
  • 「策略设置」里的可调参数（动量回看天数 / R² 下限 / 买入得分下限 等）只有在选中某策略后才会出现；未选中即显示「未选择策略」，属正常交互，不是参数丢失。
