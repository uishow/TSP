四、备份点（执行前必做）

按 TSP 升级惯例，填行情前必须备份四张行情分区。本回填只动 kline_daily（新增更早分区），但为稳妥仍先 tar 备份：
# 宿主机执行（容器外）
tar czf ~/tsp_kline_daily_backup_$(date +%Y%m%d).tgz \
    -C /Users/beryllewis/private/stock/codex/TSP/data-local kline_daily
# 另建议一并备份 kline_daily_enriched / kline_etf_daily / kline_etf_enriched
tar czf ~/tsp_kline_backup_$(date +%Y%m%d).tgz \
    -C /Users/beryllewis/private/stock/codex/TSP/data-local \
    kline_daily kline_daily_enriched kline_etf_daily kline_etf_enriched

脚本自身也会在写入前把 kline_daily 复制到 data-local/backups/ 作双保险。

八、风险与缓解

风险缓解

执行时间长预计 20~60 分钟；先单月验证再全量；可断点续跑
容器外无法跑 app 栈脚本在容器内用应用运行时执行（宿主 venv 未装上游 app 栈，已确认）
写坏行情分区先备份 + dry-run + 单月灰度；仅新增分区不覆盖现有数据
